# Toolkit assets

Brand SVGs from [Devicon](https://github.com/devicons/devicon), pinned to commit `32fe1d3b3f36ad11f90ab94f7db59738139c2bf6`. Original variants retained unchanged; see LICENSE.devicon.txt. Technology logos remain the property of their respective owners.

Source pattern: `https://raw.githubusercontent.com/devicons/devicon/32fe1d3b3f36ad11f90ab94f7db59738139c2bf6/icons/NAME/NAME-original.svg`.

`concept-*` SVGs are original portfolio pictograms for LLM integrations, MCP, PennyLane (quantum circuit), Linode (cloud infrastructure), VR, and IoT; these are conceptual symbols, not claimed official brand marks.

All SVGs were parsed and checked for scripts, event handlers, embedded images, and external references. They are served locally as decorative images alongside visible names. No package dependency or external image request is needed.
